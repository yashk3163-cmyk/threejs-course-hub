# Build an explainer video (Prompt F)

Used for the video capstones: P11-CH05 (Capstone D) and P14-CH01 (final explainer), and for any approved video project.

```
Build the approved explainer-video project [PROJECT-ID]. Begin with the audience, learning objective,
source verification, script, storyboard, shot list, scene/timeline plan, narration and caption plan,
asset manifest and licences. Then implement a reusable Three.js scene with deterministic time-based
animation (frame N is rendered at t = N / fps). Provide a quick canvas-capture path where supported
(MediaRecorder with isTypeSupported negotiation) and a frame-by-frame rendering plus FFmpeg path.
Validate resolution, frame rate, frame count, duration, timing, audio sync, export settings and
playback to the extent the tools permit, and inspect the final encode with ffprobe. Keep frames and
master videos out of Git; commit the generation scripts, configuration, manifest and regeneration
command. Include all source code, commands, sources, asset licences and honest test results. Do not
claim a finished video exists unless it has been rendered and verified.
```
